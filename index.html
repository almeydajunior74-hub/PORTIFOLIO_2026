Sobre

Atualmente, direciono minha carreira para as áreas de Desenvolvimento Back-end e DevOps, com grande interesse em automação, computação em nuvem, infraestrutura e desenvolvimento de aplicações escaláveis. PROJETOS

Pinterest fake Python

Desenvolvi uma aplicação web para compartilhamento de fotos utilizando Flask como framework principal. O projeto conta com banco de dados SQLite para armazenamento das informações, sistema de cadastro e autenticação de usuários, criptografia de senhas para maior segurança e páginas estáticas para apresentação do conteúdo.

Calculadora Uber

Aplicação para auxiliar motoristas de aplicativo no acompanhamento dos resultados financeiros de suas jornadas de trabalho. O sistema recebe informações como valor do combustível, quilômetros rodados, tempo trabalhado, eficiência do veículo (km/l) e faturamento obtido. Com base nesses dados, a aplicação calcula os custos da operação, o lucro estimado e indicadores de desempenho

Analise de dados com pandas

Aplicação de análise de dados utilizando Pandas para tratamento, organização e exploração de dados, e Plotly para criação de gráficos interativos e visualizações dinâmicas. O projeto permite transformar dados brutos em informações relevantes, facilitando a identificação de tendências, padrões e indicadores importantes para a tomada de decisão.

Aprendizado de maquina

Aplicação simples de Machine Learning capaz de aprender a relação entre o diâmetro de uma pizza e seu valor de venda. O modelo identifica padrões e realiza previsões automáticas de preços. O projeto demonstra conceitos fundamentais de aprendizado de máquina e escalabilidade, já que, quanto maior a quantidade de dados utilizados no treinamento, maior tende a ser a precisão das previsões.
